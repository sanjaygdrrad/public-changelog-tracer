A sleek, lightweight web application built to search, filter, and track public commit histories across any public GitHub repository within custom date ranges. Automatically export clean changelogs to Excel (`.xlsx`) files with a single click.

---

## ✨ Features

- **🔍 Custom Repository Query:** Fetch public commits for any GitHub user and repository instantly.
- **📅 Date Range Filtering:** Query commit logs between specific `From` and `To` dates.
- **📊 Export to Excel (`.xlsx`):** Download cleanly formatted spreadsheets containing commit hashes, authors, timestamps, and commit messages.
- **👁️ Live Visitor Counter:** Integrated background visitor telemetry auto-refreshed every minute.
- **🎨 Glassmorphism Navy UI:** Clean, responsive, dark-mode design powered by modern CSS.
- **⚡ Zero Build Tools Needed:** Vanilla HTML5, CSS3, and JavaScript — no heavy frameworks or npm install dependencies required.
